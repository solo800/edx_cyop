## Path Consistency Check

The script sets paths relative to `here::here()`:

```r
PROJECT_ROOT <- here::here()
DATA_RAW <- file.path(PROJECT_ROOT, "data", "raw")
DATA_PROCESSED <- file.path(PROJECT_ROOT, "data")
LOCAL_DATA <- file.path(PROJECT_ROOT, "local_data")
```

**Verify these still work in the new repo structure:**

- `cyo_script.R` is at root → `here::here()` resolves to repo root via `.Rproj` ✓
- `data/dvf_houses_clean.csv` → `file.path(DATA_PROCESSED, "dvf_houses_clean.csv")` ✓
- `data/raw/communes_2025.csv` → `file.path(DATA_RAW, "communes_2025.csv")` ✓
- `data/raw/filosofi_2020/...` → `file.path(DATA_RAW, "filosofi_2020", ...)` ✓

**⚠️ Important:** In the dev repo, the script lives in `scripts/cyo_script.R`. In the submission repo it should be at root. Since the script uses `here::here()` (not paths relative to its own location), this move should be transparent. But verify by running it.

**⚠️ Also check:** The Rmd file may have its own path references (e.g., sourcing the script, loading data for inline results). Make sure those still resolve from root.

## README.md Template

```markdown
# Finding Home in France: A Data-Driven Approach to City Selection

**HarvardX PH125.9x Data Science Capstone — Choose Your Own Project**  
**Author:** Adam Solomon

## Overview

This project analyzes French real estate transaction data (DVF) alongside
climate, demographic, economic, and political indicators to identify optimal
cities for relocation from Paris. Three supervised models (Linear Regression,
Random Forest, XGBoost) predict house prices across seven target cities, and
K-means clustering reveals distinct market tiers at the commune level.

## How to Run

1. Clone this repository
2. Open `cyo_edx.Rproj` in RStudio
3. Source `cyo_script.R`

The script auto-installs missing packages and loads the pre-processed
dataset directly. Full execution takes approximately 2-3 minutes.

## Data Sources

- **DVF (Demandes de Valeurs Foncières):** data.gouv.fr
- **INSEE Filosofi 2020:** Commune-level income statistics
- **Météo France:** 30-year climate normals
- **INSEE RP 2020:** Population demographics
- **Ministère de l'Intérieur:** 2022 presidential election results
```
